# Herald docs samples

The Dart code on the [Herald website](https://mkhytarmkhoian.github.io/herald/). Each snippet sits
between `// --8<-- [start:name]` and `// --8<-- [end:name]` markers, and the site pulls it in by
file and name, so a snippet that stops compiling fails CI rather than going stale on the site.

The testing guide's snippets are real tests, in `test/`.
